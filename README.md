# ОГЭ·Информатика

Сайт подготовки к ОГЭ по информатике: 300 уроков, ~70 интерактивных практик и нейронка-провожатый
на DeepSeek с дневными лимитами токенов, как круг в GPT.

Сборка не нужна: открываешь `index.html` двойным щелчком — и всё работает.
Хостинг: любой статический (GitHub Pages, Netlify, свой сервер).

---

## Что внутри

| Часть | Где лежит | Что делает |
|---|---|---|
| Страницы и оболочка | `index.html`, `styles/*` | Главная, уроки, провожатый, прогресс, медиа, тарифы, админка |

### Карта сайта

- `#/home` — главная: следующий шаг, прогресс, входной тест
- `#/test` — входной тест, 5 вопросов, разбор по темам
- `#/lessons` — 300 элементов, фильтры по модулю и типу, поиск
- `#/lesson/42` — урок: теория, задачи с проверкой, разбор каждой задачи
- `#/tutor` — провожатый: чат, режимы трат, остаток токенов
- `#/progress` — прогресс по модулям, слабые темы, экспорт/импорт
- `#/media` — все картинки и озвучка сайта
- `#/plans` — тарифы, режимы, промокоды
- `#/admin` — правка уроков, ключ DeepSeek, лимиты, бэкап (пароль по умолчанию `admin`)

## Как поднять у себя

1. Скачай папку целиком, открой `index.html` — сайт работает без сервера.
2. Чтобы включить нейронку, положи ключ DeepSeek в `config/deepseek-key.js`:

   ```js
   window.DEEPSEEK_API_KEY = "sk-...";
   ```

   Без ключа провожатый работает в простом режиме: объясняет тему урока, лайфхаки и типичные ошибки.
3. Ключ можно ввести и в админке (вкладка «AI») — он сохранится в браузере и перекроет файл.

## Как править уроки

Уроки лежат в `data/lessons/module-*.js` — это обычные JS-файлы со списком объектов.
Сайт читает собранный `data/lessons-bundle.js`, поэтому после правки модулей:

```powershell
node tools/build-lessons.js
```

Модуль обязан возвращать массив уроков:

```js
(function () {
  "use strict";
  var M = "Системы счисления";
  return [ { id: 1, module: M, title: "…", kind: "lesson", theory: "…", tasks: [ … ] } ];
})();
```

Разметка теории: `**жирный**`, `*курсив*`, `` `код` ``, блок `~~~`, лайфхак строкой `> **Лайфхак.** …`,
ошибка строкой `!! **Ошибка.** …`.

Быстрая правка одного поля урока (сам заэкранирует переносы и кавычки):

```powershell
node tools/patch-lesson-config.js --file data/lessons/module-03-algorithms.js `
  --lesson 44 --field theory --text tools/patch/m03-44.txt
```

Правки из админки не меняют файлы: они сохраняются в браузере поверх базы (localStorage).

## Проверки (запускать после правок)

```powershell
node tools/build-lessons.js      # собрать бандл и проверить нумерацию
node tools/check-content.js      # схемы уроков, задачи, решения практик
node tools/test-practices.js     # каждое решение практики в мини-интерпретаторе
node tools/test-python.js        # 64 теста мини-интерпретатора Python
node tools/smoke-test.js         # страницы, движки, лимиты, разметка — без браузера
node tools/scan-balance.js data/lessons/module-08-graphs.js   # скобки в файле
```

Все шесть должны отработать без ошибок.

## Тарифы и лимиты

| Тариф | Цена | Токенов в день | Режимы |
|---|---|---|---|
| Без подписки | 0 ₽ | 50 000 | Эконом |
| Старт | 490 ₽/мес | 250 000 | Эконом, Стандарт |
| Про | 1490 ₽/мес | 500 000 | все, включая полного агента |

Сверх лимита тарифа начисляется бонус за прогресс: до 40 000 токенов за пройденные уроки.
Режим трат выбирается в панели провожатого; недоступный режим помечен замком.
Расход считается по факту ответа (prompt + completion) и виден кружком в шапке.

## Что важно знать перед продажей

- Ключ DeepSeek в браузере может увести любой. Для живого сайта с оплатой нужен свой прокси —
  см. `docs/ARCHITECTURE.md`.
- Прогресс и правки лежат в localStorage: нужна авторизация и хранение на сервере.
- Оплата пока переключается вручную (промокоды `START30`, `PRO30`, `SCHOOL`) — платежи подключаются отдельно.
- Позиционирование: помощник, который готовит черновики и разборы, решение проверяет человек.

## Медиа

Кадры и озвучка считаются локально (FLUX + TTS) и лежат в `assets/`.
Имена файлов прописаны в `scripts/core/assets.js`: положил файл с тем же именем — сайт его показывает.
Сейчас озвучка настоящая (`assets/audio/greet.mp3`), а кадры — схемы-заглушки
(`assets/images/*.png`), нарисованные `node tools/make-placeholders.js`.
Настоящий рендер `hero.jpg` автоматически перекроет заглушку `hero.png`.

Какая картинка где стоит — видно на странице `#/media`, подробности — в `docs/MEDIA.md`.
