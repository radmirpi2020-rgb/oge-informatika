# Информатика: два курса — 5–9 класс и подготовка к ОГЭ

Сайт-курс информатики за 5–9 класс: 300 уроков, ~70 интерактивных практик и нейронка-провожатый
на DeepSeek с дневными лимитами токенов, как круг в GPT.

**На сайте два отдельных курса**, переключатель — в сайдбаре и на каждой странице:

| Курс | Что внутри |
|---|---|
| **Информатика 5–9 класс** (`base`, 300 уроков, id 1–300) | школьная программа: уроки, практики, проекты |
| **Подготовка к ОГЭ** (`oge`, 100 уроков, id 1001–1100) | 16 заданий ОГЭ, 21 балл, 150 минут; короткий трек на 85 уроков для старта в марте |

Прогресс у курсов раздельный: id не пересекаются, поэтому проценты считаются независимо.

Курс ОГЭ собирается генератором из шаблона: `node tools/build-oge-course.js`. Политика простая:
тяжёлое скачиваем и делаем в настоящей программе (LibreOffice, Кумир, Python), лёгкое симулируем
в сайте, но каждое практическое задание несколько раз обязательно делается вживую — всего
32 живых прогона, из них 11 на время.

- Шаблон и правила курса ОГЭ: `docs/OGE-COURSE-TEMPLATE.md`
- Готовый курс (генерируется): `docs/OGE-COURSE-CONTENT.md`
- План подготовки по неделям: `docs/OGE-2026-PLAN.md`, исходники: `docs/OGE-COURSE.md`
- Как устроено разделение курсов: `docs/CONTRACT.md`, §9

Сборка не нужна: открываешь `index.html` двойным щелчком — и всё работает.
Хостинг: любой статический (GitHub Pages, Netlify, свой сервер).

## Где живёт контент: база или файлы

Контент курсов можно держать **в PostgreSQL и редактировать в Payload CMS** (папка `server/`),
а сайт либо берёт его оттуда по REST, либо работает от файлов — переключается одним файлом:

| Режим | Как включить | Поведение |
|---|---|---|
| Файлы (по умолчанию) | `config/api.js` → `window.SITE_API = ""` | сайт открывается даже по `file://`, без сервера и интернета |
| База | `window.SITE_API = "http://127.0.0.1:3000"` | курсы, модули и уроки грузятся из Payload; недоступен сервер — сайт молча остаётся на файлах |

Админка контента — админка Payload (`http://localhost:3000/admin`): курсы, модули, уроки с задачами
и практиками, медиа, тарифы, черновики и версии. Своя браузерная админка (`#/admin`) осталась для
того, что живёт в браузере: ключ DeepSeek, лимиты, локальные правки.

- Запуск сервера и базы: `server/README.md`
- Быстро: `cd server && pnpm install && pnpm db:start && pnpm seed && pnpm publish:content && pnpm dev`
- Выгрузить базу в файлы сайта (снимок для офлайна): `node tools/export-from-payload.js`

## Как поднять у себя

1. Скачай папку целиком, открой `index.html` — сайт работает без сервера.
2. Чтобы включить нейронку, положи ключ DeepSeek в `config/deepseek-key.js`:

   ```js
   window.DEEPSEEK_API_KEY = "sk-...";
   ```

   Без ключа провожатый работает в простом режиме: объясняет тему урока, лайфхаки и типичные ошибки.
3. Ключ можно ввести и в админке (вкладка «AI») — он сохранится в браузере и перекроет файл.

## Как править уроки

Уроки лежат в `data/lessons/module-*.js` — это обычные JS-файлы со списком объектов.
Сайт читает собранный `data/lessons-bundle.js`, поэтому после правки модулей:

```powershell
node tools/build-lessons.js
```

Модуль обязан возвращать массив уроков:

```js
(function () {
  "use strict";
  var M = "Системы счисления";
  return [ { id: 1, module: M, title: "…", kind: "lesson", theory: "…", tasks: [ … ] } ];
})();
```

Разметка теории: `**жирный**`, `*курсив*`, `` `код` ``, блок `~~~`, лайфхак строкой `> **Лайфхак.** …`,
ошибка строкой `!! **Ошибка.** …`.

Быстрая правка одного поля урока (сам заэкранирует переносы и кавычки):

```powershell
node tools/patch-lesson-config.js --file data/lessons/module-03-algorithms.js `
  --lesson 44 --field theory --text tools/patch/m03-44.txt
```

Правки из админки не меняют файлы: они сохраняются в браузере поверх базы (localStorage).

## Проверки (запускать после правок)

```powershell
node tools/build-lessons.js      # собрать бандл и проверить нумерацию
```

Все семь проверок без сервера должны отработать без ошибок; восьмая — только в режиме «база».

## Тарифы и лимиты

Доступ к курсу и доступ к нейронке — разные вещи: можно взять только курс, а провожатого добавить позже.

| Тариф | Цена | Нейронка | Токенов в день | Режимы |
|---|---|---|---|---|
| Бесплатный | 0 ₽ | нет | — | — |
| Полный курс | 490 ₽/мес | нет | — | — |
| Максимум | 990 ₽/мес | есть | 100 000 | Эконом, Стандарт, Полный агент |

В тарифах без нейронки кружок в шапке показывает прочерк, режимы трат закрыты,
а панель провожатого объясняет, что входит в «Максимум» и сколько он стоит.

На тарифе с нейронкой сверх лимита начисляется бонус за прогресс: до 40 000 токенов за пройденные уроки.
Режим трат выбирается в панели провожатого; недоступный режим помечен замком.
Расход считается по факту ответа (prompt + completion) и виден кружком в шапке.

## Что важно знать перед продажей

- Ключ DeepSeek в браузере может увести любой. Для живого сайта с оплатой нужен свой прокси —
  см. `docs/ARCHITECTURE.md`.
- Прогресс и правки лежат в localStorage: нужна авторизация и хранение на сервере.
- Оплата пока переключается вручную (промокоды `START30`, `PRO30`, `SCHOOL`) — платежи подключаются отдельно.
- Позиционирование: помощник, который готовит черновики и разборы, решение проверяет человек.

## Медиа

Кадры и озвучка считаются локально (FLUX + TTS) и лежат в `assets/`.
Имена файлов прописаны в `scripts/core/assets.js`: положил файл с тем же именем — сайт его показывает.
Сейчас озвучка настоящая (`assets/audio/greet.mp3`), а кадры — схемы-заглушки
(`assets/images/*.png`), нарисованные `node tools/make-placeholders.js`.
Настоящий рендер `hero.jpg` автоматически перекроет заглушку `hero.png`.

Какая картинка где стоит — видно на странице `#/media`, подробности — в `docs/MEDIA.md`.
