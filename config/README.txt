КЛЮЧ DEEPSEEK — КУДА ЕГО ПОЛОЖИТЬ
==================================

1. Создай файл рядом с этим README (в этой же папке config/):

   config/deepseek-key.local.js        ← именно .local, он не коммитится

2. Внутри ровно одна строка:

   window.DEEPSEEK_API_KEY = "sk-твой-ключ";

3. Всё. Обнови страницу сайта (F5). Провожатый начнёт отвечать через DeepSeek.

ПОЧЕМУ .LOCAL, А НЕ ПРОСТО deepseek-key.js
------------------------------------------
Файл config/deepseek-key.js лежит в git и служит шаблоном. Если вписать ключ
туда, он попадёт в историю репозитория и останется там навсегда, даже если
потом строку удалить. Поэтому ключ живёт только в config/deepseek-key.local.js:
этот файл перечислен в .gitignore и в репозиторий не попадает.

В index.html local-файл подключён ПОСЛЕ шаблона, поэтому перекрывает его,
а если файла нет — ничего не ломается.

СМЕНА КЛЮЧА БЕЗ ПРАВКИ ФАЙЛА
----------------------------
Админка → раздел «Нейронка» → поле «Ключ DeepSeek». Ключ сохранится
в localStorage этого браузера и перекроет значение из файлов.

Если ключа нет нигде — сайт работает как обычно, просто нейронка молчит
и вместо ответа показывает короткий разбор урока без расхода токенов.

ВАЖНО ПРО БЕЗОПАСНОСТЬ
----------------------
Ключ, который лежит в браузере, может увести любой, кто откроет страницу
и нажмёт F12. Поэтому:

- для локальной разработки и проверки — нормально;
- для живого сайта с платными тарифами — обязательно спрятать ключ
  за своим сервером (прокси), иначе его используют за твой счёт.

Как это сделать позже, написано в docs/ARCHITECTURE.md, раздел «Прокси для ключа».
