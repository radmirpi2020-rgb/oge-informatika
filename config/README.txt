КЛЮЧ DEEPSEEK — КУДА ЕГО ПОЛОЖИТЬ
==================================

1. Создай файл рядом с этим README (в этой же папке config/):

   config/deepseek-key.js

2. Внутри ровно одна строка:

   window.DEEPSEEK_API_KEY = "sk-твой-ключ";

3. Всё. Обнови страницу сайта (F5). В шапке появится надпись «AI: подключён».

Если файла нет — сайт работает как обычно, просто нейронка выключена
и вместо неё показывается подсказка «ключ не найден».

ВАЖНО ПРО БЕЗОПАСНОСТЬ
----------------------
Ключ, который лежит в браузере, может увести любой, кто откроет страницу
и нажмёт F12. Поэтому:

- для локальной разработки и проверки — нормально;
- для живого сайта с платными тарифами — обязательно спрятать ключ
  за своим сервером (прокси), иначе его используют за твой счёт.

Как это сделать позже, написано в docs/ARCHITECTURE.md, раздел «Прокси для ключа».

СМЕНА КЛЮЧА БЕЗ ПРАВКИ ФАЙЛА
-----------------------------
Админка → вкладка «AI» → поле «Ключ DeepSeek». Ключ сохранится в localStorage
этого браузера и перекроет значение из файла.
