Переработка практик: интерактив вместо текста
Что не так сейчас
Практика — это большая текстовая задача со спойлером ответа. Ученик читает, думает, подсматривает. Это не проверяет навык, это проверяет чтение.

Что должно быть
Практика — это действие: пишешь код, запускаешь, видишь результат. Или собираешь программу из блоков и смотришь, как робот идёт по лабиринту.

Три типа интерактивных практик
Тип 1. Редактор кода (Python или псевдокод)
Ученик пишет код в браузере, нажимает «Запустить», видит результат или ошибку. Проверка — сравнение с ожидаемым выводом.

Что встраивается:

Простой редактор кода (CodeMirror или textarea с подсветкой)

Кнопка «Запустить»

Блок вывода

Кнопка «Проверить» — сверяет вывод с эталоном

Кнопка «Показать решение» — открывает эталонный код

Для чего подходит:

Системы счисления (перевод чисел, вывод результата)

Логика (вычисление выражений)

Алгоритмы (циклы, условия)

Кодирование (подсчёт байтов, символов)

Таблицы (эмуляция формул)

Графы (поиск путей, обход)

Тип 2. Блочный редактор (как Scratch)
Ученик перетаскивает блоки «вперёд 2», «назад 1», «повтори 3 раза», «если стена — повернуть». Запускает — робот идёт по сетке.

Что встраивается:

Поле с сеткой (например 10×10)

Робот-исполнитель (Чертёжник, Кузнечик, Муравей)

Палитра блоков слева

Область программы справа

Кнопка «Запустить» — анимация движения

Кнопка «Сбросить»

Цель: дойти до флага, нарисовать фигуру, собрать все монетки

Для чего подходит:

Алгоритмы и исполнители (уроки 8–11)

Вспомогательные алгоритмы (процедуры)

Циклы и условия

Логика (условия в блоках «если-иначе»)

Тип 3. Песочница с проверкой (полуавтомат)
Ученик пишет ответ в поле, но система проверяет не только финальный ответ, а показывает промежуточные шаги. Например, для перевода числа — показывает разложение по степеням. Для изображения — считает размер по шагам.

Что встраивается:

Поле ввода

Кнопка «Показать шаги» — раскрывает пошаговое решение с подсветкой

Кнопка «Проверить» — сверяет

Для чего подходит:

Системы счисления

Кодирование текста, изображений, звука

Файловая система, маски

Электронные таблицы

Базы данных

Передача информации

Как это выглядит для ученика
Пример практики «Кузнечик» (блочный редактор)
Слева палитра блоков:

text
[ Вперёд __ ]  [ Назад __ ]  [ Повтори __ раз ]
[ Если стена — повернуть ]  [ Стоп ]
Справа область программы. Снизу сетка 10×10 с Кузнечиком в точке 0 и флагом в точке 8.

Ученик перетаскивает: Повтори 4 раза [ Вперёд 3, Назад 1 ]. Жмёт «Запустить». Кузнечик прыгает по клеткам, останавливается на 8. Появляется «✓ Цель достигнута».

Если не туда — «✗ Кузнечик на клетке 5, до флага 3 шага. Попробуй ещё».

Пример практики «Логика» (редактор кода)
python
A = True
B = False
result = (A and B) or (not B and A)
print(result)
Ученик нажимает «Запустить». В блоке вывода появляется True. Жмёт «Проверить» — сверка с эталоном.

Пример практики «СУММ» (песочница)
text
A1 = [2, 3, 5, 7, 9]
Формула: =СУММ(A1:A5)
Ученик вводит ответ 26. Жмёт «Показать шаги»:

text
СУММ = 2 + 3 + 5 + 7 + 9
     = 26
Что нужно технически
Для редактора кода:

Встроить CodeMirror (лёгкий, 100 КБ) или использовать <textarea> с подсветкой через highlight.js

Для Python в браузере — Pyodide (WebAssembly). Тяжёлый (~10 МБ), но работает офлайн

Альтернатива: собственный интерпретатор подмножества Python на JS. Проще и легче

Для блочного редактора:

Собственная реализация на SVG или Canvas

Или Blockly от Google (готовое, ~500 КБ)

Робот рисуется как <circle> или <rect> на SVG-сетке

Для песочницы:

Чистый HTML + JS, ничего дополнительного

Порядок внедрения
Сначала песочницы (4, 14, 18, 25) — проще всего, дают 40% эффекта
